Paste each file into the voice tool exactly as written. They contain no timestamps, stage directions or headings. Blank lines between paragraphs are the natural pauses.

VOICE SETTINGS (suggested)
- Speed: about 0.95 to 1.0 (roughly 150 words per minute). Warm, friendly, upbeat. Not a news-reader voice.
- If the tool has a "paragraph pause" setting, use 0.6 to 0.8 seconds.
- Generate each paragraph separately if you want to line them up with the screen recording, then join them.

PRONUNCIATION
- "I-U-I-C dot D-C" is written phonetically. Change it if the community says the name differently (for example "I U I C dot D C" or a single word).
- "D-C", "PIN", "PayPal" and "Sweet Savor Cafe" are spelled so a voice reads them naturally.

KEPT ACCURATE (from the production notes)
- Store purchases finish on the website; the food cart is separate.
- PayPal is a demonstration; no money moves.
- Texts: a staff member sends the prepared message; nothing is sent automatically.
- Lock-screen alerts depend on the device and permission; no promise made.
- The customer profile is saved on the device, not a cloud account.
- Sales figures summarize recorded orders, not settled payments.
- No PIN codes, passcodes, passwords, or phone numbers are spoken.

IF YOU CHANGE THE SCRIPT LATER
Keep sentences short, avoid symbols and abbreviations, and spell out anything that should be spoken a special way.
